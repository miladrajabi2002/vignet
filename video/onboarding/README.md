# ویدیوی معرفی ویجنت

نسخهٔ عمومی فارسی قدم دوم آنبوردینگ. فیلم ۱ دقیقه و ۴۶ ثانیه، ۱۹۲۰×۱۰۸۰ و ۶۰ فریم‌برثانیه است.

- `vigent-intro-fa.mp4` فایل تأییدشدهٔ پخش است. مسیر `/media/onboarding/vigent-intro-fa.mp4` به همین فایل اشاره می‌کند.
- `vigent-intro-fa-source.zip` پروژهٔ قابل‌ویرایش است. بعد از استخراج، `README.md` راهنمای پیش‌نمایش و رندر، `story.mjs` متن گویندگی و `visual/` اجزای تصویری را دارد. بسته بیرون از مسیر فایل‌های عمومی پنل است.
- گویندگی فارسی با `google/gemini-3.8-flash-tts`، صدای `Algieba` و یک برداشت کامل از طریق OpenRouter انجام شده است.
