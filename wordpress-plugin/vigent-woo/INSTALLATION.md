# راهنمای نصب افزونه ویجنت 4.2.0

## پیش‌نیازها

- WordPress 5.8 یا بالاتر
- PHP 7.4 یا بالاتر
- WooCommerce 6 یا بالاتر
- امکان ارسال درخواست HTTPS از هاست به `vigent.ir`

## نصب و اتصال

1. ZIP افزونه را از پنل ویجنت دریافت و از مسیر «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب کنید.
2. در پنل ویجنت یک اتصال فروشگاه با آدرس دقیق سایت بسازید.
3. در مدیریت WordPress وارد منوی «ویجنت» شوید و «اتصال» را بزنید.
4. افزونه با یک چالش یک‌بارمصرف مالکیت سایت را اثبات می‌کند و اطلاعات webhook را امن دریافت می‌کند؛ نیازی به کپی‌کردن secret نیست.
5. محصولات را یک‌بار ارسال کنید. ارسال سفارش‌های موجود اختیاری و صرفاً برای پیگیری است.

## رفتار همگام‌سازی

- ارسال اولیه در بسته‌های حداکثر ۵۰ رویدادی انجام می‌شود؛ هر بسته فقط یک درخواست شبکه است.
- پس از راه‌اندازی، ساخت/ویرایش/حذف محصول و ایجاد/تغییر سفارش در صف محلی ثبت می‌شود.
- چند تغییر پشت‌سرهم یک مورد با هم ادغام می‌شوند و فقط آخرین وضعیت آن ارسال می‌شود.
- صف حداکثر هر پنج دقیقه ارسال می‌شود؛ صف خالی هیچ درخواست شبکه‌ای ایجاد نمی‌کند.
- پاسخ ناموفق باعث حذف صف نمی‌شود و تغییرات در نوبت بعد دوباره ارسال می‌شوند.
- دسته‌بندی‌های محصول همراه محصول ارسال می‌شوند.

## دکمه‌های صفحهٔ افزونه

- «ارسال تغییرات»: صف فعلی را همان لحظه ارسال می‌کند.
- «ارسال کامل محصولات»: همهٔ محصولات را دوباره به‌شکل upsert می‌فرستد؛ بعد از ارتقا به 4.2.0 یک‌بار برای انتقال دسته‌بندی محصولات قدیمی استفاده کنید.
- «بروزرسانی»: نسخهٔ جدید را با بروزرسان استاندارد WordPress نصب می‌کند.

## ارتقا از نسخهٔ قبلی

نصب مجدد لازم نیست. دکمهٔ بروزرسانی تنظیمات و اتصال موجود را حفظ می‌کند، cron کامل ۳۰ دقیقه‌ای را حذف می‌کند و retryهای محصول/سفارش را به صف جدید منتقل می‌کند. فقط نسخه‌های قدیمی که دکمهٔ بروزرسانی ندارند باید یک‌بار با ZIP تازه جایگزین شوند.

## محدودهٔ سفارش

ارسال سفارش برای نمایش وضعیت و پشتیبانی مشتری است. نسخهٔ 4.2.0 هیچ endpoint یا مجوزی برای ایجاد سفارش، فروش خودکار یا دریافت پرداخت توسط ایجنت اضافه نمی‌کند.

## عیب‌یابی سریع

- اگر اتصال برقرار نشد، دسترسی خروجی HTTPS به `vigent.ir` و فعال‌بودن REST API WordPress را بررسی کنید.
- اگر صف ارسال نشد، دکمهٔ «ارسال تغییرات» پیام واقعی سرور را نمایش می‌دهد و داده‌ها برای تلاش بعدی حفظ می‌شوند.
- اگر دسته‌بندی محصولات قدیمی دیده نمی‌شود، یک‌بار «ارسال کامل محصولات» را اجرا کنید.
