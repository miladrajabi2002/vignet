افزونهٔ اتصال وردپرس به ویجنت — نوشته‌ها و برگه‌ها را به پایگاه دانش ایجنت می‌فرستد و در صورت فعال‌بودن ووکامرس، محصولات و سفارش‌ها را هم همگام می‌کند.

== Description ==

این افزونه سایت وردپرسی شما را به ایجنت هوشمند ویجنت متصل می‌کند:

* **همهٔ سایت‌های وردپرسی:** نوشته‌ها و برگه‌های منتشرشده به‌صورت خودکار وارد پایگاه دانش ایجنت می‌شوند.
* **فروشگاه‌های ووکامرسی:** علاوه بر محتوا، محصولات و سفارش‌ها هم همگام می‌شوند.
* **داشبورد وردپرس:** یک ویجت کوچک در داشبورد اصلی وردپرس، وضعیت اتصال را نشان می‌دهد.
* **آمار زنده:** چارت‌های ۷ روزه، تفکیک سفارش‌ها بر اساس وضعیت و آمار محتوا.
* **سیستم Retry:** رویدادهای ناموفق به‌صورت خودکار دوباره ارسال می‌شوند.
* **WP-CLI:** برای اتوماسیون و مدیریت از خط فرمان.

هر تغییری به‌صورت لحظه‌ای به webhook ویجنت ارسال می‌شود.

= امکانات نسخه ۳.۰.۰ =

* منوی اصلی در پیشخوان وردپرس با ۶ تب: داشبورد، تنظیمات، هم‌گام‌سازی، آمار سایت، ابزارها، راهنما
* Live Status: نمایش زندهٔ وضعیت اتصال با auto-refresh هر ۳۰ ثانیه
* نوار پیشرفت زنده برای هم‌گام‌سازی کامل (AJAX-based)
* دکمهٔ «تست اتصال» با بازخورد فوری
* سیستم Retry برای رویدادهای ناموفق (۵ بار با exponential backoff)
* فیلتر محصولات: همه / منتشرشده / دارای قیمت / دسته‌بندی خاص
* ویجت داشبورد وردپرس برای نمایش وضعیت اتصال
* WP-CLI commands: `wp vigent status|test-connection|sync|retry-queue`
* پشتیبانی از زبان‌های multiple (فارسی + انگلیسی + .pot)
* سازگار با HPOS (High-Performance Order Storage) ووکامرس
* سازگار با ووکامرس فارسی و همهٔ نسخه‌های ووکامرس ۶ به بالا
* uninstall.php برای پاک‌سازی کامل داده‌ها هنگام حذف
* رفع Fatal error متد `get_billing()`

== Installation ==

= نصب افزونه =

1. فایل zip را از پنل ویجنت (صفحهٔ «محصولات» یا «اتصالات») دانلود کنید.
2. در وردپرس به «افزونه‌ها ← افزودن ← بارگذاری افزونه» بروید و فایل را آپلود کنید.
3. افزونه را فعال کنید. یک منوی اصلی با نام «ویجنت» ظاهر می‌شود.

= راه‌اندازی =

1. در پنل ویجنت یک اتصال ووکامرس بسازید (آدرس سایت را وارد کنید).
2. ویجنت به‌صورت خودکار آدرس webhook و کلید امنیتی تولید می‌کند.
3. در وردپرس به «ویجنت ← تنظیمات اتصال» بروید و این مقادیر را جای‌گذاری کنید.
4. دکمهٔ «تست اتصال» را بزنید.
5. به تب «هم‌گام‌سازی» بروید و داده‌های اولیه را ارسال کنید.

== Frequently Asked Questions ==

= آیا بدون ووکامرس هم کار می‌کند؟ =

بله. هم‌گام‌سازی محتوا (نوشته‌ها و برگه‌ها) روی هر سایت وردپرسی کار می‌کند.

= آیا با ووکامرس فارسی سازگار است؟ =

بله، کاملاً سازگار است. افزونه از هوک‌های استاندارد ووکامرس استفاده می‌کند و با همهٔ نسخه‌های ووکامرس فارسی کار می‌کند.

= آیا با HPOS سازگار است؟ =

بله. از متدهای فردی `get_billing_first_name()` و ... استفاده می‌شود که با HPOS سازگارند.

= خطای ۴۰۱ در پنل ویجنت؟ =

به‌دلیل اشتباه بودن Consumer Key/Secret است. در ووکامرس کلید جدید بسازید یا از حالت webhook-only استفاده کنید.

= آیا داده‌ها هنگام حذف افزونه پاک می‌شوند؟ =

بله. فایل `uninstall.php` هنگام حذف افزونه همهٔ تنظیمات، صف retry و transients را پاک می‌کند.
