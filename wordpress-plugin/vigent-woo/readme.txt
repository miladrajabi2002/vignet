افزونهٔ اتصال وردپرس به ویجنت — نوشته‌ها و برگه‌ها را به پایگاه دانش ایجنت می‌فرستد و در صورت فعال‌بودن ووکامرس، محصولات و سفارش‌ها را هم همگام می‌کند.

== Description ==

این افزونه سایت وردپرسی شما را به ایجنت هوشمند ویجنت متصل می‌کند:

* **همهٔ سایت‌های وردپرسی:** نوشته‌ها و برگه‌های منتشرشده به‌صورت خودکار وارد پایگاه دانش ایجنت می‌شوند تا ایجنت بتواند از محتوای سایت شما به مشتریان پاسخ بدهد.
* **فروشگاه‌های ووکامرسی:** علاوه بر محتوا، محصولات و سفارش‌ها هم همگام می‌شوند تا ایجنت همیشه از قیمت، موجودی و وضعیت سفارش خبر داشته باشد.

هر تغییری به‌صورت لحظه‌ای به webhook ویجنت ارسال می‌شود و دکمه‌های هم‌گام‌سازی کامل دستی هم در صفحهٔ تنظیمات قرار دارند.

= امکانات =

* ارسال خودکار نوشته‌ها و برگه‌ها به پایگاه دانش ایجنت (بدون نیاز به ووکامرس)
* ارسال خودکار رویدادهای ساخت، ویرایش و حذف محصول (با ووکامرس)
* ارسال خودکار رویدادهای تغییر وضعیت سفارش (با ووکامرس)
* دکمه‌های هم‌گام‌سازی کامل دستی برای محتوا، محصولات و سفارش‌ها
* امضای HMAC-SHA256 برای امنیت webhook
* صفحهٔ تنظیمات فارسی

== Installation ==

= نصب افزونه =

1. فایل zip را از پنل ویجنت (صفحهٔ «اتصالات») دانلود کنید و از طریق
   «افزونه‌ها → افزودن → بارگذاری افزونه» نصب کنید.
2. افزونهٔ «ویجنت — اتصال وردپرس و ووکامرس» را فعال کنید.

= دریافت آدرس webhook از پنل ویجنت =

1. وارد پنل ویجنت (https://vigent.ir) شوید.
2. به صفحهٔ «اتصالات» → بخش «فروشگاه آنلاین» بروید.
3. روی «افزودن فروشگاه» کلیک کنید و آدرس سایت خود را وارد کنید.
4. پس از ذخیره، آدرس webhook و کلید امنیتی نمایش داده می‌شود. هر دو را کپی کنید.

= تنظیم کلید امنیتی =

1. در پیشخوان وردپرس به مسیر «WooCommerce → ویجنت» (یا اگر ووکامرس ندارید: «تنظیمات → ویجنت») بروید.
2. آدرس webhook و کلید امنیتی را جای‌گذاری کنید و «ذخیره تنظیمات» را بزنید.
3. برای ارسال اولیهٔ همهٔ داده‌ها، از دکمه‌های هم‌گام‌سازی کامل پایین صفحه استفاده کنید.

== Frequently Asked Questions ==

= آیا بدون ووکامرس هم کار می‌کند؟ =

بله. هم‌گام‌سازی محتوا (نوشته‌ها و برگه‌ها) روی هر سایت وردپرسی کار می‌کند. اگر بعداً ووکامرس نصب
کنید، گزینه‌های محصول و سفارش هم به‌صورت خودکار در تنظیمات ظاهر می‌شوند.

= آیا نیاز به REST API ووکامرس داریم؟ =

خیر. این افزونه از هوک‌های PHP استفاده می‌کند و داده‌ها را از طریق webhook به ویجنت می‌فرستد.

= آیا اطلاعات مشتری هم ارسال می‌شود؟ =

بله، برای هر سفارش نام، شماره تماس و ایمیل صورت‌حساب ارسال می‌شود تا ویجنت بتواند سفارش را
به مشتری شناسایی‌شده در پنل CRM پیوند بزند.
